## Task Coverage

Aufgabe 3 covers conditional probability and probability composition in a learning-strategy scenario. The official prompt asks students to compute non-passing probability, missing conditional strategy probabilities, the unconditional probability of using strategy 3, the reverse conditional probability of passing given strategy 2 with solution path, and an at-least-one probability for ten independent sampled students.

Aufgabe 4 covers set operations and conditional probability in a finite Laplace experiment. The official prompt asks students to compute the cardinalities of `A ∩ B̄` and `Ā ∪ B`, then enter the correct notation and value for the probability that `A` occurs given that `B` did not occur.

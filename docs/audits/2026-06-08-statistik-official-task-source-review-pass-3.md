The official prompt asks students to interpret the coefficient of `Stud`, infer the sample size from the model output, compute a 90% confidence interval for `βBevDichte`, decide a 10% significance-level hypothesis test for `βBevDichte = 0`, and compute a model prediction for Göttingen.

The official prompt gives six paired observations, asks students to compute `s²x`, use provided rounded values to calculate `ρxy`, interpret the result or a fallback value, judge a causal claim, and sketch a possible scatterplot for `ρxy = 0`.
